# Lens design

Lens uses the **Focus Match** metaphor: a focus ring locks onto the right
subject, then a mismatch guard refuses a near-miss.

## Tokens

| Token | Value |
|---|---|
| Canvas | `#F2F3F7` |
| Surface | `#FFFFFF` |
| Ink | `#101828` |
| Muted | `#667085` |
| Line | `#E4E7EC` |
| Lens | `#D97706` |
| Bright | `#F59E0B` |
| Fog | `#FEF3C7` |

Typography is Outfit for display, Figtree for body, and IBM Plex Mono for
scores, ids, costs, and guard reasons.

## Required motifs

- Focus-ring + lock-notch brand mark
- Balanced specimen art on both hero flanks with a clear center
- Match strip under hero CTAs
- Structured-tag marquee
- A mismatch chapter that makes refusal the product hook
- One-page review desk with pairing table, focus meters, cost chips, and batch status

The shared Capstones harness remains authoritative for motion, Lenis,
scrollbars, README screenshots, git, and submission shipping. UI and docs use
no em or en dashes.
